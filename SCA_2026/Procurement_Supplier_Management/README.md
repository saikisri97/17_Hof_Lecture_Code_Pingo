# Procurement & Supplier Management

Open slides/Procurement_Class.pptx to teach. Share slides/Procurement_Student.pdf before class. The student PDF omits solution/significance and Pingo slides.

Open Procurement_Student.ipynb in Jupyter or upload it to Google Colab. Run setup and Baseline, then each task at its starting value before changing the arrow-marked setting. All five experiments are independent. The notebook includes the same synthetic CSVs for standalone execution. The solution notebook contains the prescribed changed settings, outputs and answers.

Files: student and solution notebooks; Pingo XML and answer key; data CSVs and dictionary; generation script; helper source; task map; validation records; slide export script; chapter register. No published Colab or TinyURL has been created for this chapter. Notebook links in the slides point to the installed local files on the lecturer’s computer. For sharing, upload the notebooks to Colab and replace these links with published destinations.

Python dependencies: pandas, numpy, matplotlib, IPython. Notebook execution additionally uses nbformat, nbclient and ipykernel. PDF export uses LibreOffice and pypdf. See data/DATA_POLICY.md for definitions and assumptions.

The revised case uses observed synthetic deliveries and explicit buyer rules. It contains no predictive model or optimisation model. The original 2025 files remain unchanged.
